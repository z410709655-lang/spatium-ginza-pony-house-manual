# SPATIUM GINZA PONY House Manual

Guest-facing web version of the SPATIUM GINZA PONY in-room guide.

## Files

- `index.html`: main online manual page
- `assets/`: photos and supporting images used by the page

## Update Flow

1. Edit `index.html` and related files.
2. Commit the changes to GitHub.
3. Netlify can redeploy from this repository so the guest URL stays stable.

## Notes

- Do not publish room passwords, Wi-Fi passwords, private phone numbers, or internal operation details.
- Keep changeable stay information on the separate check-in notice.
